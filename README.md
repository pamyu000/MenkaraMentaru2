# メンカラメンタル診断

GitHub Pagesで公開できるスマホ向け診断サイトです。

## 構成

- `index.html`：診断本体
- `google-apps-script.gs`：匿名統計をGoogleスプレッドシートへ保存・集計するためのGoogle Apps Script

## 公開手順

### 1. GitHub Pages

このフォルダの `index.html` をGitHubリポジトリへ置き、GitHub Pagesを有効化します。

### 2. 統計用スプレッドシート

1. Googleスプレッドシートを新規作成
2. 「拡張機能」→「Apps Script」
3. `google-apps-script.gs` の内容を貼り付けて保存
4. 「デプロイ」→「新しいデプロイ」
5. 種類は「ウェブアプリ」
6. 実行するユーザー：自分
7. アクセスできるユーザー：全員
8. デプロイしてウェブアプリURLを取得
9. `index.html` の `const API_URL = "";` にそのURLを入れる
10. GitHubへ再アップロード

### 3. 収集するデータ

統計目的で以下を保存します。

- Q1〜Q5の回答番号
- Q2=④/⑤の場合のみ追加質問の回答番号
- 16タイプの結果コード
- メンカラ変化サブタイプ
- 診断日

名前、メールアドレス、担当（推し）の名前などは保存しません。

## 注意

このサンプルは「匿名の診断統計」を想定しています。公開前に、実際の運用環境に合わせてプライバシーに関する説明文や利用目的をサイト上で確認できるようにしてください。

## 診断ロジック

Q1〜Q5から16タイプを決定し、Q2=④/⑤の場合は「メンカラ変化タイプ」を別軸で付与します。

現時点では診断ロジックを実装したたたき台です。実際に公開する前に、想定する回答パターンを確認して微調整してください。
